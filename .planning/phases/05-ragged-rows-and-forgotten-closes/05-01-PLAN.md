<objective>
Make the `header` option the row-width authority for `db:write_csv`: a row shorter than the header
pads with empty cells, a row longer than it throws a Pattern 1 error naming the row ordinal and
both counts, and a writer opened with no header enforces nothing.

Purpose: `db:read_csv`'s pinned `KEEP_NON_EMPTY` policy never pads, so an unpadded ragged row comes
back silently misaligned against its own header. FMT-07 is what makes a file written by a sloppy
script still read back aligned.
Output: `CsvWriter::header_width` and the pad/throw block in `src/lua_runner.cpp`, one catalogue
line in `src/csv_write.cpp`, and the TEST-10 round-trip suite.
</objective>
