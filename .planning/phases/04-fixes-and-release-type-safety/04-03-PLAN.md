<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Lua script to the Lua VM loader | `load` turns script-supplied bytes into executable code; Lua 5.4 does not verify bytecode |
| Lua script to Expression operators | Operands are untrusted values; the error must name what the script called |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-11 | Elevation of privilege | Global `load` accepting a crafted binary chunk (arbitrary memory read/write inside the host) | critical | mitigate | Wrapper forcing mode `"t"` installed before any script runs; `LoadRefusesBinaryChunks` covers string, reader, `"b"` and `"bt"` forms; mutation to `"bt"` must fail it |
| T-04-12 | Tampering | Wrapper breaking string-form `load` semantics (env none vs nil) and so script behaviour | medium | mitigate | `...` forwards env only when given; `LoadStillAcceptsTextChunks` pins no-env, explicit env, nil mode and explicit nil env |
| T-04-13 | Elevation of privilege | Wrapper registered after the binders or by a path a script can bypass (e.g. a captured original `load`) | medium | mitigate | Installed in the constructor before `quiver`/`db` exist, original held only as an upvalue of the wrapper; acceptance checks the line order |
| T-04-14 | Repudiation | Operand errors naming no operation (hard to trace in agent-written scripts) | low | mitigate | `to_expression(o, operation)` with Lua event names; golden re-baseline limited to the listed keys |
| T-04-15 | Tampering | Dead-branch removal silently changing a data_type name or a files write | low | mitigate | Golden byte-identical across the refactor commit; lowercase mutation must fail golden |
</threat_model>
