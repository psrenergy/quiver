| WRITE-01 | concurrency | **Unresolved.** This project has never made a concurrency guarantee for Lua file operations. | Boundary | Description |
|----------|-------------|
| Lua script to filesystem | A script-supplied path string crosses into `std::ofstream`. The sandbox root is the directory containing the database file. |
| Lua script to C++ writer | Arbitrary Lua values (tables, functions, userdata, non-finite numbers, invalid UTF-8 byte strings) cross into the cell formatter. |
| Emitted file to downstream consumer | The CSV leaves Quiver and may be opened by a spreadsheet or another parser outside Quiver's control. |
