<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Bun ↔ `libquiver_c` | Hand-written symbol table and hand-written byte offsets are the only description of the ABI. `bun test` does not typecheck, so a wrong number reaches runtime as an out-of-bounds read with no diagnostic. |
| Bun USIZE return ↔ JS number | A USIZE FFI return arrives as a `bigint`; an unwrapped comparison against a number is always false. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02 | Tampering | `readUiMetadataAt`'s nine hand-written offsets | high | mitigate | Offsets copied from 03-RESEARCH's written-out decoder against the frozen header; `UI_METADATA_SIZE` checked against the native accessor at load; Task 3 asserts all nine fields individually, because a transposed layout still measures 64 bytes and the size gate alone cannot see it. `bunx tsc --noEmit` is run explicitly since `bun test` does not typecheck. |
| T-03-02b | Tampering | A gate that is written but unwired | high | mitigate | Task 1 requires the mutation to be **executed** — call site commented out, wiring-evidence test observed failing, call site restored. |
