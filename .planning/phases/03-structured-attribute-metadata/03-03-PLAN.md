`vocabulary::String`, `display_order::Int64`. Every string field is a plain `String`, never
`Optional{String}` — D-13 makes empty string the spelling of absence on this boundary, and the C
converter `strdup`s even an empty field so no pointer is ever null. This is a deliberate departure
from `parse_scalar_metadata`'s `default_value` handling, where a null pointer genuinely means "no
default"; note the reason in a comment so the next reader does not "fix" it into an `Optional`.

public functions, none of which take a `!` suffix since none mutates:

copy `get_scalar_metadata`'s shape exactly: a `Ref` of a zero-initialised
`C.quiver_ui_metadata_t`, `check(C.quiver_database_get_attribute_ui_metadata(...))`, parse, then
`C.quiver_database_free_ui_metadata(metadata)`, returning the parsed value.

freed with the existing `C.quiver_database_free_string_array`.
