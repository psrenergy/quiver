<user_story>
**As a** Bun consumer whose `csv.ts` hands a hand-allocated 56-byte buffer to the native library,
**I want to** be refused at load time if the native library disagrees about that struct's size,
**so that** the largest hand-allocated struct in the JS binding stops being the one exception to
the safety gate the rest of the phase built.
</user_story>

<objective>
Close the JS half of Gap 6 and the JS half of Gap 2: `quiver_csv_options_t` joins the load-time
gate as the fourth struct, `csv.ts`'s seven bare-literal offsets become named constants (the exact
inline-literal style OPT-05 exists to abolish), and the JS struct-size test stops being one a
skeptic can leave green with the gate deleted.

Purpose: `bindings/js/src/csv.ts:24` is the *larger* of the two hand-allocated JS structs, and
`bindings/js/CLAUDE.md` currently documents it as "Known, deliberately unfixed". The user decided
to close it. Once closed, that note must go — a file that documents a deferral the code has closed
is worse than no note.

Output: a four-struct gate with observable evidence, named CSV offsets, a mutation-sensitive test,
and a `bindings/js/CLAUDE.md` that describes what the code actually does.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JS heap ↔ native library | `csv.ts` and `ffi-helpers.ts` hand-allocate `Uint8Array` buffers sized by TypeScript constants and pass raw addresses to C. A constant that disagrees with the native layout is an out-of-bounds write with no compile error — Bun's FFI is untyped at the boundary and `bun test` does not typecheck. |
| published npm package ↔ S3-downloaded native | The JS binding downloads its native libraries at install time via a postinstall step, so package and native can be from different releases. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-10-01 | Tampering | `buildCsvOptionsBuffer`'s hand-allocated 56-byte buffer | high | mitigate | `CSV_OPTIONS_SIZE` + named offsets + a fourth entry in the load-time gate asserting it against `quiver_csv_options_sizeof()`. Exactly-equal passes, any difference throws. |
| T-02-10-02 | Tampering | `assertNativeStructSizes` being removable without a failing test | high | mitigate | `checkedStructNames()` record + the ordered-list assertion + the executed mutation criterion in Task 2. |
| T-02-10-03 | Spoofing | A mismatch message masked as "Cannot load native library" by moving the gate inside a tier | medium | mitigate | The gate stays in `loadLibrary()` outside all three tiers; pinned by an acceptance criterion grepping for its position. |
| T-02-10-04 | Denial of Service | A consumer who never exports CSV now hard-fails on a CSV-struct skew | low | accept | Deliberate, per D-08. Consistent with the three structs already gated. |

No package-manager install task exists in this plan (no `npm install`, no new dependency), so no
