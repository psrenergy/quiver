<objective>
Hand-edit Dart's generated bindings for the 24-byte options struct, add the two open
parameters and `hasUiConfig()`, install a load-time struct-size gate that actually calls
the accessor, and stop the suite from silently testing a stale native layout.

Purpose: two Dart-specific traps make this more than mechanical. `bindings.dart` cannot be
regenerated (a regen breaks Hub), and Dart resolves native symbols lazily, so a test suite
running against a pre-phase native library today would open databases successfully and fail
confusingly somewhere else much later. D-15's cache clearing and Pitfall 1's active call are
the two fixes.
Output: a hand-edited binding matching the frozen header, a gate whose throw path is tested,
and a `test.bat` that cannot lie to you.
</objective>
