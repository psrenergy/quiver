<objective>
Teach the Python binding the grown 24-byte options struct, the two new open parameters,
`has_ui_config()`, and a load-time struct-size gate that actually calls the accessors.

Purpose: CFFI is in ABI mode — there is no compile step and no generator to catch a wrong
cdef. A struct declaration that disagrees with the native header corrupts silently. Two of
this plan's three tasks exist because of that single property.
Output: a cdef that matches the frozen header, a `_make_options` that keeps its string
buffers alive, and two new test files including the failure-path proof.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CFFI cdef -> native library | An ABI-mode cdef is an unverified assertion about the native layout. Nothing compiles it against the real header. |
| `ffi.new("char[]")` -> struct pointer field | An owning cdata whose lifetime Python controls, reachable by C only while a Python reference exists. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | ABI-mode cdef disagreeing with the native struct | critical | mitigate | `_assert_struct_sizes` compares `ffi.sizeof` against the three native accessors at load and raises before any struct is allocated (Task 2); layout pinned by `ffi.offsetof` assertions (Task 1). |
| T-02-08 | Tampering | `ffi.new("char[]")` collected before the native read | high | mitigate | `_make_options` returns `(options, keepalive)`; all three factories bind the keepalive across the `check(...)` call (Task 1). |
| T-02-09 | Denial of Service | Native library predating this phase — missing `*_sizeof` symbol | medium | mitigate | The assertion calls each accessor and re-raises `AttributeError` as a RuntimeError naming "native library older than this binding" (Task 2, RESEARCH Pitfall 4). |
| T-02-SC | Tampering | pip installs | high | accept | No `pip install` / `uv add` occurs; the phase adds no dependency (RESEARCH Package Legitimacy Audit: not applicable). |
</threat_model>
