Regenerate Julia's `c_api.jl` against the frozen header, thread the two new options through

on the next regen while every happy-path test stays green. The gate goes in the prologue.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Generated `c_api.jl` -> native library | Generated from the headers on disk at generation time, which need not match the native library at run time (a published artifact, a stale build). |
| `generator/prologue.jl` -> `c_api.jl` | Everything hand-written must cross this boundary, or a regeneration deletes it. |
| Julia `Vector{UInt8}` -> struct pointer field | A GC-managed buffer whose pointer C reads during the call. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | Generated struct disagreeing with the loaded native library | critical | mitigate | `_assert_struct_sizes` in `__init__` compares `sizeof` against three native accessors before any FFI work (Task 2). |
| T-02-13 | Tampering | The safety gate silently deleted by the next `generator.bat` run | high | mitigate | The gate is written to `generator/prologue.jl`, and Task 2's acceptance criterion re-runs the generator and requires an EMPTY diff — proving survival rather than assuming it. |
| T-02-14 | Tampering | GC collecting the `ui_config_dir` backing buffer mid-call | high | mitigate | `build_quiver_database_options` returns the keepalive; each factory wraps its ccall in `GC.@preserve` (Task 1), the binding's documented rule. |
| T-02-15 | Denial of Service | Native library predating this phase — missing `*_sizeof` symbol | medium | mitigate | The `@ccall` is wrapped so a lookup failure is re-raised naming the version skew (Task 2). |
| T-02-SC | Tampering | Julia General registry installs | high | accept | No package is added; `Pkg.instantiate()` resolves the already-declared `CEnum` / `Clang` dependencies (RESEARCH Package Legitimacy Audit: not applicable). |
</threat_model>
