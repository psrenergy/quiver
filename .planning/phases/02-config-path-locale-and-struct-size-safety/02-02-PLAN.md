<objective>
Grow JS's hand-rolled options buffer from 8 to 24 bytes safely, and give the binding a
load-time struct-size gate.

Purpose: this is the one place in the repo where a wrong number is a native out-of-bounds
write with no compile error, no exception, no generator and no fallback symbol — Bun
cannot call `quiver_database_options_default` (struct-by-value, oven-sh/bun#6139). It
also carries a second hazard CONTEXT.md did not name: the two new fields are POINTERS into
separately-allocated string buffers, and a correct 24-byte buffer holding a collected
pointer is still a use-after-free.
Output: a 24-byte buffer built from named offsets with its child allocations kept alive, a
three-struct load-time assertion whose throw path is actually exercised by a test, and the
first `bindings/js/test/ffi-helpers.test.ts` this repo has ever had.
</objective>
