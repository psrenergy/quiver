## Flagged Assumptions (carried to the verifier, not resolved by a check)

- **FA-1 (Lua parity, closed file):** in Lua a closed file is still an expression read by path; in Julia
  `Binary.close!` calls `quiver_binary_file_close`, which deletes the C handle, so a closed `Binary.File` has no
  handle left to convert and raises `Null argument` (pinned by "Closed Binary.File is not an operand"). Closing
  this gap needs a C API change (a separate close and free for binary files), which this phase rules out.
- **FA-2 (RESEARCH Pitfall 4):** `Quiver.get_metadata(Binary.File(path))` on an unopened handle returns the
  handle's empty metadata, while `Quiver.get_metadata(Quiver.Expression(file))` reads the `.toml`. This is the
  C++ virtual's semantics, unchanged from today's `Binary.get_metadata`, and is not pinned here.
- **FA-3:** the other `.ptr` ccalls in `src/binary/file.jl` (read, write, get_metadata, ...) stay without
  `GC.@preserve`; this phase touches only the struct line there. Their exposure is the one the old forwarders
  already had.

Edge-probe accounting (spec-less fallback, 11 probe items for JUL-01..03, DOC-01..02): this plan authors 7. Six
are explicit truths (JUL-02 interrupted/parallel as the `GC.@preserve` rule; JUL-03 adjacency, empty, ordering,
run twice, lifetime) and one is a backstop truth (JUL-01 parallel). 09-02 authors the other 4 (DOC-01 as a
backstop, DOC-02 adjacency, empty, ordering as explicit truths): 11 = 9 explicit + 2 backstop + 0 flagged.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Julia object lifetime → C handle | A Julia finalizer frees the C handle of a `Binary.File` or `Expression`; a `.ptr` loaded for a ccall is only valid while its owner is rooted. |
| Julia caller → filesystem (`Quiver.save`) | A new path writes from a raw file; Julia is a trusted host, so no sandbox applies (LuaRunner policy only). |
| caller's file handle → expression engine | Converting or saving from a file must never close or reuse the caller's handle. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-01 | Tampering / DoS (use-after-free) | `_binop`, `_unop`, `ifelse`, `save`, `get_metadata`, `aggregate*`, `*_agents`, `Expression(file)` | medium | mitigate | every converted local and the file are named in a `GC.@preserve` around their ccall (at least 12 sites, gate-checked); "Expression from a raw Binary.File outlives it" forces `GC.gc()` between operations and saves |
