### Note on the integration report's wording

The checker described the unclosed-writer case as "out-of-scope per the requirements' declined-warning
item." That conflates two different things: the *warning* was declined for the milestone, the *flush*
(WRITE-06) is core scope. Its own E2E scripts all called `close()` explicitly, so it did not exercise
the unclosed path live — but that path is covered by the two TEST-11 cases, which Phase 5's verifier
read directly and confirmed pass with the `LuaRunner` alive. **No coverage gap; a wording error in
the report only.**
