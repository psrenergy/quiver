# External Integrations

**Analysis Date:** 2026-10-02

## APIs & External Services

No runtime web APIs. The library is fully local. External services are publishing and CI targets only.

**Package registries:**
- PyPI (`quiverdb`) - `.github/workflows/publish-python.yml`
  - Build: cibuildwheel; publish only on `workflow_dispatch`, `skip-existing: true`, environment `pypi`
  - Auth: PyPI trusted publishing (OIDC), no token
- npm (`quiverdb`) - `.github/workflows/publish-js.yml`
  - Native libs downloaded from S3 into `bindings/js/libs/<platform>/`, asserted present in `npm pack` tarball
  - Auth: npm Trusted Publishing (OIDC, `id-token: write`, environment `npm`), npm >= 11.5.1, `--loglevel verbose` load-bearing; `npm view` guard skips re-publish
- Julia General registry via mirror repo `psrenergy/Quiver.jl` - `.github/workflows/publish-julia.yml`
  - Wipes mirror (keeps `.git/`), copies `bindings/julia/`, copies `tests/schemas/` into `test/schemas/`, overlays generated `Artifacts.toml`, opens PR
  - Auth: `QUIVER_JL_TOKEN` secret; runs on `[self-hosted, linux]` runner
- pub.dev (`quiverdb`) - no publish workflow detected; Dart builds natives from source via `bindings/dart/hook/build.dart`

**Coverage:**
- Codecov - `ci.yml` coverage jobs with flags `cpp`, `julia`, `dart`, `python`; config `codecov.yml`
  - Auth: `CODECOV_TOKEN` secret

## Data Storage

**Databases:**
- SQLite (embedded, statically fetched v3.53.4)
  - Connection: file path or `:memory:` passed to `Database(path, options)` / `from_schema` / `from_migrations`
  - Client: direct sqlite3 C API in `src/` (no ORM)

**File Storage:**
- Local filesystem only: `.qvr` binary files + `.toml` sidecars (`src/binary/`), CSV import/export (`src/csv/`, `src/database_csv_*.cpp`). Lua file ops sandboxed to the DB directory (`resolve_sandboxed_path`, `src/lua_runner.cpp`)
- AWS S3 (CI only): bucket `julia-artifacts`, prefix `quiver/<version>/native/<platform>/<file>`, uploaded `--acl public-read` by `scripts/ci/native_s3.sh`; downloaded via `https://<bucket>.s3.amazonaws.com/...`
  - Auth: ambient IAM role on self-hosted runner, no AWS key secrets
  - Julia tarballs + `Artifacts.toml` generated by `scripts/julia/generate_artifacts.jl`

**Caching:**
- None at runtime. CI: FetchContent `_deps` / sccache cache in `.github/actions/build-cpp` (key includes toolchain fingerprint + `runner.arch`)

## CI/CD & Deployment

**Hosting:**
- GitHub Releases (`ncipollo/release-action`, `skipIfReleaseExists`) for tag `v<version>`

**CI Pipeline:**
- GitHub Actions (`.github/workflows/`):
  - `ci.yml` - build matrix ubuntu/ubuntu-arm/windows/macos x Release/Debug, ctest, coverage, clang-format check (`uvx` 22.1.8), actionlint, bun-test matrix
  - `bump-version.yml` - runs `scripts/assert_version.py bump <part>`, opens PR via `peter-evans/create-pull-request`
  - `publish.yml` - orchestrator: assert tag -> `publish-s3.yml` -> tag + release -> parallel `publish-julia.yml` / `publish-python.yml` / `publish-js.yml`, dispatched via `scripts/ci/dispatch_workflow.sh` (top-level `workflow_dispatch`, not `workflow_call`, because OIDC validates the top-level filename)
  - `publish-s3.yml` - builds natives; Linux in pinned-digest manylinux images via `scripts/build_native_linux.sh` (glibc/GLIBCXX gate, `$ORIGIN` rpath), macOS/Windows via `.github/actions/build-cpp`; macOS `install_name_tool` + `codesign --force --sign -`
- Full reference: `.github/AGENTS.md`

## Native Library Loading

- Python: `bindings/python/src/quiverdb/_loader.py` - CFFI `ffi.dlopen` of bundled `libquiver` then `libquiver_c`, fallback to system search for dev builds
- JS: `bindings/js/src/loader.ts` - `bun:ffi` `dlopen` with hand-written symbol table; on Windows prepends lib dir to PATH so `libquiver_c.dll` finds `libquiver.dll`
- Julia: `bindings/julia/src/c_api.jl` - Artifacts.toml hash resolved at precompile; hardcodes `libquiver.0.dylib` on macOS
- Dart: native-assets `CodeAsset` registered by `bindings/dart/hook/build.dart` (unversioned names required)
